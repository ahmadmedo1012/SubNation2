# إدارة جلسة WhatsApp OTP

## لوحة إدارة OpenWA (الرابط المباشر)

**<https://openwa-gateway-7aaa.onrender.com>**

بيانات الدخول (سريّة — لا تشاركها):

- اسم المستخدم: `subnation`
- كلمة المرور: مولّدة قويّة، محفوظة في متغيرات خدمة Render (`DASHBOARD_PASSWORD`)

من اللوحة يمكنك: عرض كل الجلسات وحالاتها، إنشاء جلسة جديدة، تشغيلها،
ربطها عبر **QR** (يظهر مباشرة ويتحدث تلقائيًا) أو عبر **رمز الهاتف**،
و**حذف** أي جلسة نهائيًا — بدون أي حاجة إلى مفتاح API أو لوحة SubNation.

ملاحظات أمنية:

- تسجيل الدخول محمي بقفل تلقائي: 5 محاولات خاطئة خلال 15 دقيقة = قفل 15 دقيقة.
- الجلسة كوكي موقّعة HMAC (httpOnly) صالحة 12 ساعة.
- مفتاح `OPENWA_API_KEY` لا يصل للمتصفح أبدًا — كل العمليات تتم عبر الخادم.
- البوابة على الخطة المجانية: أول طلب بعد خمول قد يستغرق ~30-60 ثانية
  (إعادة إقلاع) ثم تعمل بسرعتها الطبيعية. الخدمة **تنام بالتصميم** منذ
  جولة 2026-09-20 — لا يوجد أي self-ping أو keep-alive؛ أول طلب حقيقي
  يوقظها ويستعيد الجلسات المقترنة من الاعتمادات المحفوظة (انظر
  `docs/free-tier-optimization-2026-09-20.md`).

## لوحة SubNation الإدارية (مسار بديل)

**<https://subnation.ly/admin/whatsapp>** — نفس العمليات عبر أدمن SubNation
(صلاحية settings) لبقّية الفريق دون منحهم مفتاح البوابة.

## ربط الرقم لأول مرة (الطريقة الموصى بها: رمز الهاتف)

1. سجّل دخولك للوحة OpenWA أعلاه.
2. أنشئ جلسة باسم `subnation-otp` (أو استخدم الموجودة) ثم اضغط **تشغيل**.
3. اضغط **رمز ربط** واكتب رقم الهاتف الذي سيُرسل أكواد الدخول بصيغة دولية
   مثل `21891XXXXXXX` دون مسافات.
4. في هاتف واتساب افتح: **الإعدادات ← الأجهزة المرتبطة ← ربط جهاز برقم الهاتف بدلاً من QR**.
5. أدخل الرمز الظاهر في اللوحة. ستتحول الحالة إلى **جاهزة ✓** تلقائيًا.

زر **QR** متاح كبديل (يفتح نافذة تعرض الرمز مباشرة مع تحديث تلقائي كل 3 ثوانٍ).
زر **حذف** يمسح الاعتماد نهائيًا ويتطلب ربطًا جديدًا.

## كيف أعرف أن القناة تعمل؟

- الصفحة الرئيسية للوحة تعرض بطاقات: عدد الجلسات / الجاهزة / التي تنتظر الربط.
- حالة «جاهزة ✓» + «آخر تسليم: تم التسليم» = كل شيء سليم.
- في SubNation: صفحة الدخول تعرض زر WhatsApp مع تلميح صادق إذا كانت
  القناة قيد الربط، و`/api/auth/providers` يعيد `whatsapp_status`.

## حفظ الجلسة بعد إعادة تشغيل Render

خدمة OpenWA منفصلة عن مستودع SubNation وهي التي تملك ملفات اعتماد Baileys.
لكي لا تضيع الجلسة عند إعادة النشر أو إعادة التشغيل، يجب ضبط المتغيرات التالية
في خدمة OpenWA نفسها (الأوليان مطلوبتان، والثالث اختياري):

- `PERSISTENCE_URL` = رابط PostgreSQL الخاص بـ Neon نفسه المستخدم في `DATABASE_URL`.
- `OPENWA_API_KEY` = نفس المفتاح الموجود في `WHATSAPP_OTP_API_KEY` داخل خدمة `subnation`.
- `OPENWA_CREDENTIALS_KEY` = (اختياري) مفتاح مستقل لتشفير اعتمادات الجلسة
  (AES-256-GCM) في جدول `openwa_sessions`. إن تُرك فارغًا استمر الاشتقاق
  القديم من `OPENWA_API_KEY` نفسه (توافق كامل مع الاعتمادات المحفوظة
  مسبقًا)؛ وعند ضبطه (32 حرفًا فأكثر) تُفكّ الكتل القديمة وتُعاد تشفيرها
  بالمفتاح الجديد تلقائيًا (إعادة تعيين شفافة — راجع ترويسة `src/persist.ts`
  في مستودع openwa).

البوابة تنشئ جدول `openwa_sessions` تلقائيًا، وتخزن الاعتمادات مشفّرة (AES-256-GCM)
قبل الكتابة، وتستعيدها عند كل إقلاع. لا تنقل `OPENWA_API_KEY` أو بيانات اعتماد
اللوحة إلى Vercel أو كود المتصفح.
