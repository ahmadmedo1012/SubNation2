## ما نُفِّذ

### أ) لوحة إدارة OpenWA المستقلة (طلب المشغّل المباشر)
- **الرابط: <https://openwa-gateway-7aaa.onrender.com>** — تسجيل دخول باسم
  مستخدم وكلمة مرور (متغيرات `DASHBOARD_USERNAME/DASHBOARD_PASSWORD`).
- كوكي موقّع HMAC-SHA256 (httpOnly, SameSite=Lax, Secure, 12h) + سر تسجيل
  مستقل `DASHBOARD_SESSION_SECRET`.
- قفل تخمين: 5 محاولات خاطئة/15 دقيقة لكل IP حقيقي (آخر إدخال XFF)
  → قفل 15 دقيقة. مقارنات ثابتة الزمن.
- واجهة عربية RTL بثيم واتساب الداكن: بطاقات إحصائية، إنشاء/تشغيل جلسة،
  **QR حي يتحدث كل 3 ثوانٍ**، **رمز ربط هاتفي** بزر نسخ، حذف بتأكيد.
- **مفتاح API لا يصل للمتصفح أبدًا** — كل العمليات عبر الخادم بالكوكي.
- عقد REST تحت `/api` لم يُمس (X-API-Key كما هو) — توافق كامل مع SubNation.

### ب) تحصين أمني بعد مراجعة فريق أحمر (مثبتة حية قبل الإصلاح)
- P1: تجاوز القفل عبر تزوير أول إدخال XFF → المفتاح الآن على آخر إدخال
  (ما أضافه وكيل Render الموثوق).
- P1: DoS معالجي (scryptSync عند كل تحقق كوكي) → تخزين سر واحد مؤقت.
- P2: كوكي بنسبة مئوية تالفة كان يُسقط كل المسارات (500) → guarded decode.
- P2: X-Frame-Options DENY + CSP صارمة + nosniff + no-referrer +
  تعطيل X-Powered-By + no-store للصفحات الديناميكية.
- P3: فحص Origin/Host لكل طفرات /dash (CSRF) + مقارنة مفتاح API
  ثابتة الزمن.

### ج) صدق القناة في SubNation
- `getWhatsAppGatewayReadiness()` — فحص حي بحالة الجلسة مع كاش 30 ثانية
  (لا ready زائف أبدًا؛ فشل الفحص = unknown).
- `/api/auth/providers` يضيف `whatsapp_status` (back-compat محفوظ).
- `session_not_ready` → سبب مستقل `whatsapp_not_paired` (503) برسالة
  عربية صادقة بدل «غير مفعّلة» المضللة.
- تلميح صادق تحت زر WhatsApp في login/register عندما تكون القناة غير
  جاهزة (لا يحجب المحاولة).

## الاختبارات والبوابات

- 6 اختبارات جديدة (فحص الجاهزية + الخريطة) — **102 ملف/884 اختبار خلفي،
  46 ملف/274 اختبار واجهة، كلها خضراء** + typecheck نظيف + lint 0 + CI أخضر
  (أول CI أخضر منذ إدخال انجراف r94).
- محاكاة ضخمة (32 فحصًا، 3 شخصيات: زائر/مشغّل/مهاجم): **32 PASS / 0 FAIL**
  — تشمل إثبات موت تجاوز القفل، حجب CSRF عبر نطاق شرير، رفض كوكي مزوّع،
  عدم تسريب المفتاح في أي استجابة، وعقد REST سليمًا.

## ما تبقى على المشغّل (خطوة واحدة فقط)

**اربط رقم الواتساب من اللوحة**: سجّل الدخول إلى
<https://openwa-gateway-7aaa.onrender.com> → جلسة `subnation-otp` بانتظار
الربط → اضغط «رمز ربط» وأدخل `21891XXXXXXX` → أدخل الرمز في هاتفك
(واتساب ← الأجهزة المرتبطة ← ربط جهاز برقم الهاتف) → تصبح الحالة
«جاهزة ✓» ويعمل دخول WhatsApp فورًا. البديل: زر QR مباشرة.

ملاحظات: 5 محاولات دخول خاطئة تقفل اللوحة 15 دقيقة (حماية مقصودة)؛
أول فتح بعد خمول قد يستغرق ~30-60 ثانية (خطة مجانية + keep-alive ذاتي
كل 4 دقائق).
